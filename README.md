
# Phần 1 (Phân tích Excel)
Bảng "Xấu" vi phạm quy tắc vàng (dùng Merge Cell, hàng trống ngắt quãng, tổng cộng ở giữa). Bảng "Đúng" chuẩn Database (phẳng, đúng 1 Header Row, không gộp ô, tách biệt rõ Field/Record).

# Phần 2 (Triển khai)

Word: Viết SRS nền tảng đấu giá nhà đất với phân cấp Heading 1, 2, 3.

Excel: Tính chiết khấu, giá thuê và tra cứu hoa hồng bằng VLOOKUP trên dữ liệu chuẩn.

PowerPoint: Thiết kế Pitch Deck gọi vốn theo Rule 10/20/30 (tối đa 10 slide), tiêu chí 1 Slide - 1 Thông điệp, có nhiều White Space.

# Phần 3 (Kiểm thử lỗi trôi vùng VLOOKUP)
Thêm dấu đô la ($) bằng phím F4 (ví dụ: $A$2:$B$100) để cố định vùng dữ liệu tra cứu khi kéo công thức.
